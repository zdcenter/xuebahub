# 更新日志 (CHANGELOG.md)

## [Unreleased] - 2026-10-04

### 新增与修复 (Feature & Bug Fixes)
- **百度网盘高精度解析引擎升级 (解决加密分享与多层目录解析)**:
  - 攻克了百度网盘新版提取码校验机制：必须在首次打开链接建立 Session 获取 `share_uk` 与 `shareid` 后，通过带参数的 `POST /share/verify` 接口换取鉴权 `BDCLND` Cookie。
  - 实现了支持带文件夹属性（`isdir == 1`）的递归穿透统计：针对例如用户提供的分享链接 `https://pan.baidu.com/s/1U79T5cTlVfD8ixE9No9yGw?pwd=2xr4`，系统自动进入一级目录“翟鹏飞”穿透遍历内部全部资源（含 2 节 MP4 视频与 2 份 PDF），精准汇总得出真实容量 `2.34 GB`、识别出包含视频课格式并提取更新时间 `2024-07-29`。
  - 重启并热更新 Go 后端服务，接口秒级响应。
- **后台管理表单精简与去冗余**:
  - 彻底取消新增资料表单与修改资料弹窗中历史遗留的共用“文件预估大小”输入项，避免用户多次重复输入。
  - 发布或修改资料时，系统自动根据填写的夸克网盘实际容量或百度网盘实际容量智能同步回写主资源 `file_size` 字段，前后端数据结构完美对齐。
- **夸克网盘两阶段解析引擎**:
  - 修复了夸克网盘链接（如 `https://pan.quark.cn/s/447614e03c4f`）直接请求详情接口被拦截导致误报“需要提取码或文件已加密”的问题。
  - 接入夸克官方 `POST /1/clouddrive/share/sharepage/token` 凭据交换流程，获取有效 `stoken`。
  - 实现了支持文件夹深度的容量探测，对于含多集视频的文件夹自动计算合并容量（经实测 `447614e03c4f` 正确解析为 1.39 GB 高清视频课）。
- **后台管理系统优化**:
  - 新增资料录入/修改时失焦或点击“⚡ 自动读取大小与格式”按钮时，自动回填文件格式、容量大小与课程名称。
  - 完善了修改弹窗中的上架状态持久化逻辑，防止修改后自动变为下架。
  - **资料标题支持直接点击预览**：后台列表中资料标题现已改为链接形态，点击可直接在新标签页中打开前台对应的公开详情页。
- **前台详情页交互与转化增强**:
  - **网盘明文地址展示与一键复制**：转存下载区域新增网盘真实 URL 明文展示栏与独立的“📋 复制链接”按钮，提取码同步标记，给予用户更强信任感。
  - **转存与浏览数据精准互通**：移除了原先假数字兜底，前台真实读取数据库中的 `save_count` 与 `view_count`，并在用户点击“立即转存”或“复制链接”时实时调用 `/track-save` 原子累加，前后端数据完全一致。
  - **修复转存统计跨端口上报问题**：修正了前端页面因未指定后端服务端口（8080）导致统计请求未送达 Go 服务的缺陷，并在 `astro.config.mjs` 中接入 `/api` 反向代理，确保用户点击“复制链接”或“立即转存”时，后台转存次数即时 +1。
  - **后台列表新增“🔄 刷新数据”**：方便随时手动获取最新转存与浏览量统计数据。
- **网盘独立多态规格与专属数据统计 (核心架构升级)**:
  - **数据库表结构扩展 (`resource_links`)**：为各网盘链接独立增加了 `file_size` (实际容量)、`file_type` (文件格式)、`resource_desc` (特色说明) 及 `updated_at` (更新时间)，彻底解耦以往单资料所有网盘共享单一规格的痛点。
  - **各网盘转存量独立精细化追踪**：升级了 `TrackSaveClick` 与 `TrackResourceSave`，支持按具体网盘 `link_id` 单独累加点击量；前台点击复制或转存时，该网盘的转存数与全局总转存数同时实时响应更新。
  - **前台详情页专属网盘卡片**：各网盘卡片独立展示自己的真实大小（如夸克 1.39 GB 高清视频 vs 百度 12.4 MB PDF 打印版）、独立转存人次、更新时效及特色描述。
  - **前台详情页顶部精简重构**：彻底取消了顶部原先模糊、与各网盘冲突的“共用文件大小/文件格式/更新时间/累计转存”4 格网格，替换为清晰的“收录时间、体量与页面真实浏览量”元数据栏，所有文件规格与转存数据聚焦到具体的各网盘专属下载卡片中，页面层次清晰自然。
  - **后台表单与列表细化**：新增/修改资料时支持对夸克与百度分别配置各自的大小与说明，后台列表“转存/浏览”列自动展开各网盘的独立转化统计明细。
- **Astro 前台动态 SSR 接入**:
  - 采用 `@astrojs/node` SSR 渲染模式，移除静态预构建路由依赖，确保后台发布的新资料即时访问可用。
