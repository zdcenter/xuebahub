  - **根治嵌套多层目录分享时探测结果为 0 B 的问题**:
    - 查明原因：夸克网盘（及大多数网盘）分享文件夹时，文件夹节点本身的 `size` 均为 `0`；当分享包含深层嵌套子文件夹（如“自然/实验/数学/语文”）时，原本仅探测一层子目录无法深入到深层的真正视频文件，导致子目录全为文件夹且容量合计为 `0 B`；
    - **深度递归穿透算法**：在 `NetdiskParserService` 中引入 `fetchQuarkDirRecursive` 递归穿透机制，支持下探多级子目录，自动累加深层各文件字节数，计算出真实总容量；
    - **0 B 友好兜底**：当分享包含庞大深层目录、各叶子节点未全部拉取时，系统智能识别为【完整视频合集包】或【完整资源合集】，杜绝直接显示 `0 B`；
  - **中文视频课智能推断**:
    - 标题或目录中包含“视频”、“微课”、“动画”、“课程”等关键词时，即使底层全是深层目录，系统也能精准判定为【高清视频课】，彻底告别被默认判定为【PDF】的失真现象；
  - **前台展示与表单保护优化**:

    - 后台录入/修改时不再用 `0 B` 强制覆盖管理员填写的容量。
