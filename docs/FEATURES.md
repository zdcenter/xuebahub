# 学霸资料库功能规格说明书 (FEATURES.md)

## 1. 核心定位与业务模式
专为中小学与成人职考（教师资格证、考公、考研）打造的精选学习资料库平台，核心在于轻体量、高转化、高裂变传播与网盘拉新返佣（夸克网盘为主、百度网盘为辅）。

## 2. 系统功能模块

### 2.1 用户前台 (Astro + SSR + TailwindCSS)
- **多维度筛选**: 学段（小学、初中、高中、大学、职考考证）、年级、科目、教材版本联动。
- **资源详情展示**: 动态渲染，支持无缝 SSR 直出，无 404 延迟问题。
- **高转化引导**:
  - **网盘独立多态卡片**：各网盘（夸克、百度）拥有独立的文件容量、格式标注、专属转存计数与更新时效，彻底避免跨网盘内容规格失真。
  - **明文链接与一键复制**：提供真实 URL 预览框与剪贴板一键写入，增强访客信任。
  - **夸克网盘专属醒目转存入口**（移动端直跳/PC 端原画提取）。
  - 标签式展示：高清微课、原题手写解析、重点圈画。
  - 百度网盘备用链接与提取码一键复制。

### 2.2 管理后台 (Angular 21 + Reactive Forms)
- **极速资料录入与修改**:
  - 学段、年级、学科、版本级联标签与预设项。
  - **网盘独立配置区**：支持分别为夸克网盘和百度网盘录入/修改各自的文件容量、文件格式与内容说明。
  - **彻底移除冗余共用字段**：废除表单中原有的全局“文件预估大小”输入项，各网盘规格由夸克与百度独立卡片管理并自动汇总，录入更轻巧直观。
  - 列表支持直接点击标题在新窗口预览前台，转存/浏览列细分显示各网盘具体转化数据。
  - 弹窗式修改编辑，支持一键切换上架/下架。
  - 无阻塞 Floating Toast 替代原生的弹窗拦截。
- **全网盘智能解析引擎 (⚡ 一键读取)**:
  - **夸克网盘**：通过两阶段接口（Token 交换 + 详情与目录聚合）识别真实资源标题、文件夹层级及文件总容量（如 1.39 GB）与视频/PDF 格式标识。
  - **百度网盘**：支持提取码自动捕获、验证 Cookie 交换及接口/页面元数据抓取，精准自动回填百度端文件大小、文件格式及更新时间。

### 2.3 后端核心服务 (Go Fiber v3 + GORM + PostgreSQL)
- **网盘解析服务 (`internal/service/netdisk_parser.go`)**:
  - 夸克网盘与百度网盘公开/加密分享链接的自动化信息爬取、容量合并计算、格式识别与更新时间提取。
- **统一 RESTful API**:
  - `GET /api/v1/public/resources` (前台公开资源列表)
  - `GET /api/v1/public/resources/:slug` (资源详情直出)
  - `POST /api/v1/admin/parse-netdisk` (网盘智能解析接口，支持夸克与百度网盘及提取码)
  - `GET / POST / PUT / DELETE /api/v1/admin/resources` (后台管理全套 CRUD)
