# 学霸资料库功能规格说明书 (FEATURES.md)

## 1. 核心定位与业务模式
专为中小学与成人职考（教师资格证、考公、考研）打造的精选学习资料库平台，核心在于轻体量、高转化、高裂变传播与网盘拉新返佣（夸克网盘为主、百度网盘为辅）。

## 2. 系统功能模块

### 2.1 用户前台 (Astro + SSR + TailwindCSS)
- **数据库驱动的动态多级专区导航与开箱即用分类体系 (Dynamic Multi-Level Navigation & Full Taxonomies)**:
  - **全动态后台可配置导航**：前台顶部导航（PC 端毛玻璃下拉菜单与移动端侧滑抽屉）完全由后台数据库 (`nav_menus`) 动态驱动，彻底废除前端写死逻辑。管理员在后台对一级专区、二级子菜单的任何增删改、排序、显隐切换，前台实时毫秒级生效。
  - **全学段/科目/考证常用类别全量预置 (44 专区项 + 37 标准分类)**：
    - **小学专区**：涵盖 1-3 年级基础同步、4-6 年级期末冲刺、小升初择校拔尖分班卷 (置顶)、小学奥数思维 30 讲、人教版全套、北师大/苏教版试卷、满分作文与晨读名校真题；
    - **初中专区**：涵盖七年级期中期末、八年级物理几何两极分化突围、九年级中考一轮总复习、中考历年真题分类汇编、数学圆与二次函数压轴、物理化学实验大突破、百强名校一模密卷；
    - **高中专区**：涵盖高一必修同步、高二选必突破、2026 新高考一模二模名校模拟、高考导数极值与圆锥曲线微课、九省联考/八省联考真题卷、学霸手撕笔记与思维导图；
    - **成人考证**：涵盖小学/中学教师资格证统考笔试与结构化面试、公务员国考/省考行测申论、事业单位与教师考编、考研公共课政治英语数学、初级会计职称全科题库、计算机软考中高级；
    - **实用素材与怀旧游戏**：涵盖年终汇报与答辩 PPT 模版、自媒体剪辑爆笑转场音效与 BGM 包、电商海报免抠 PNG 素材、街机与掌机模拟器合集、经典 PC 单机典藏中文版、单机 MOD 整合包。
  - **地区与归属名校针对性长尾检索**：支持按城市地区（如“广西-柳州”）和归属学校（如“柳州十二中”、“黄冈中学”）快速检索与精准直达，实现本地重点中学期末卷与小升初分班卷极高转化率。
  - **PC 端防折行强化 (Anti-Wrapping Grid)**：全导航项与标签施加 `whitespace-nowrap shrink-0` 强约束，在中等桌面宽度、侧边栏展开或缩放场景下严格单行排布，杜绝文字折行撕裂。
  - **移动端全景侧滑分类抽屉 (Mobile Navigation Drawer)**：解决移动触屏设备无 Hover 鼠标事件导致二级菜单无法弹起的痛点，提供显式【☰ 分类导航】与【📑 全部分类 ▾】按钮，展开全景手风琴面板，完整呈现所有二级下钻入口。
  - **半透明毛玻璃二级下拉菜单 (Hover Dropdowns)**：桌面端鼠标悬停即刻展开轻量毛玻璃下拉浮窗，带防抖延迟桥接与分类副标，纯 CSS 丝滑响应。
- **顶级业务频道动态导航与一流 SEO 静态目录架构 (SEO-Friendly Directory Routing)**:
  - **静态目录化路由 (Clean Path Routing)**：全面摒弃弱权重的参数形式（`/?channel=games`），升级为搜索引擎一流权重的独立目录结构（如 `/edu`、`/tools`、`/games`），各大频道独立形成顶级权重专区与清晰面包屑层级。
  - **301 永久规范重定向 (Canonical 301 Redirect)**：访问旧链接或外部带参链接（如 `/?channel=games&q=拳皇`）时，系统自动执行 HTTP 301 永久重定向至 `/games?q=拳皇`，集中页面权重（PageRank），彻底消除重复内容（Duplicate Content）隐患。
  - **`<link rel="canonical">` 权威标记注入**：每个页面 head 区自动生成规范权威 URL，强化百度/Google 对该专区的主题识别。
  - **动态从后端接口拉取在线频道**：动态拉取已上线的频道（如 📚 刚需教辅学习、🎨 实用生产力工具与素材、🎮 复古怀旧单机游戏合集）。
  - **隐藏频道彻底屏蔽与直接访问 302 规范拦截**：当管理员在后台隐藏某个频道时（`is_active = false`），前台顶部导航与页面频道胶囊自动隐藏，且该频道所有资源自动对前台不可见；访客直接在浏览器地址栏输入已隐藏频道的路径（如 `/games`）时，服务端自动执行 HTTP 302 规范重定向至网站首页，保障未开放内容不外泄。
  - **动态 Hero 与热搜智能适配**：切换至不同频道时，Hero 区域的标题、口号与热搜词动态变更为该垂类（如素材库聚焦“述职PPT模板/自媒体音效/免抠素材”，游戏库聚焦“街机500合1/模拟器/MOD整合”）。
  - **资源卡片专属频道徽标**：全域列表下每个资源卡片清晰标记对应业务频道。
- **高信息密度专业资源站布局 (High-Density Professional Resource Stream)**:
  - **彻底省略冗余占位缩略图**：移除大面积无意义的封面插图，杜绝单屏仅显3~4个资源的空泛感，全面升级为专业垂直资源站标准的高密度横向条目流（Resource Row Card）。
  - **左侧核心文件格式徽章 (Format Anchor Badge)**：精准突出文件属性（📄 PDF试卷可打印、📑 PPTX动态模板、🎬 MP4高清微课、📦 ZIP免安装绿色包），直击访客核心需求。
  - **标题与高价值信息全显**：标题支持全量长关键词展开，副标题直观提炼压轴题特点、名师手写解析或软件免解压特性。
  - **高密度规格与权威证明**：直接呈现真实文件容量（如 12.4 MB）、页数/套数规格、查阅与转存人数及存活状态。
  - **右侧直达高转化行动区**：桌面端右侧独占【⚡ 夸克极速转存】直达通道与【试看详情】入口，移动端智能自适应全宽操作条，大幅提升首屏内容承载量与网盘转存点击率。
- **多维度筛选**: 学段（小学、初中、高中、大学、职考考证）、年级、科目、教材版本联动。
- **资源详情展示 (纯净高转化与按需动态说明)**:
  - 动态渲染，支持无缝 SSR 直出，无 404 延迟问题。
  - **彻底移除不实硬编码套话**：废除死板假大空的“经整理校对去广告水印”、“名师手写解析”、“A4打印即练”等硬编码文案，消除跨频道（如PPT模板、怀旧游戏）的违和感，彻底免除站长人工整理水印的繁重运营负担。
  - **动态按需说明（有则展示，无则静默隐藏）**：仅当后台填写或自动转存抓取到真实内容简介（`description`）时，才渲染「📝 内容介绍与使用说明」模块；若字段为空，整块区域在 DOM 中完全不渲染，让页面直奔主题，最大化网盘转存点击转化。
- **高转化引导**:
  - **网盘独立多态卡片**：各网盘（夸克、百度）拥有独立的文件容量、格式标注、专属转存计数与更新时效，彻底避免跨网盘内容规格失真。
  - **明文链接与一键复制**：提供真实 URL 预览框与剪贴板一键写入，增强访客信任。
  - **夸克网盘专属醒目转存入口**（移动端直跳/PC 端原画提取）。
  - 标签式展示：高清微课、原题手写解析、重点圈画。
  - 百度网盘备用链接与提取码一键复制。
- **失效报错反馈与状态标识**:
  - **前台一键报错**：用户遇到失效、被删除链接可直接点击“⚠️ 失效报错”提交反馈，附带本地防刷与频控。
  - **失效状态前台同步与全局横幅**：检测到失效链接自动在下载专区顶部弹出黄色预警横幅，失效链接卡片自动标红置灰，直达转存按钮禁用并提示“通道失效补链中”，避免用户盲目跳转与流失。

### 2.2 管理后台 (Angular 21 + Reactive Forms)
- **网盘链接健康巡检与快速补链联动 (🛡️ 一键巡检与深度看板)**:
  - **列表三态快速过滤**：卡片头部支持一键切换“全部”、“🚨 仅看失效资料 (X)”、“⚠️ 仅看用户报错 (X)”，精准定位受损资料。
  - **资料标题行醒目预警**：含失效链接的资料自动打上“🚨 存在失效网盘 · 急需补链”高亮徽标，并提供一键唤起编辑弹窗的补链快捷入口。
  - **全状态可视化网盘徽标**：列表中每个网盘均清晰呈现 ✅正常存活（含检测时间） / ⚠️用户报错 / ❌已失效 / ⚪待检。失效网盘药丸自带红框并附带“✏️”补链按钮。
  - **巡检报告深度联动与一键补链**：巡检弹窗报告自动携带**所属资料标题（Title）与资料ID**，管理员点击“✏️ 去补链”可直接关闭巡检并打开对应资料修改窗口，无缝直达。
  - **冷却时间调控（防封频控）**：支持调控冷却时间阈值（默认 24 小时、48小时、7天等），自动跳过冷却期内刚检测过的链接，避免单日重复检测引发第三方网盘风控或带宽浪费。
  - **单链接手动立即检测**：每条链接均提供“🔍”按钮，点击后立即探测并响应式更新整行与全局状态。
- **极速资料录入与修改**:
  - 学段、年级、学科、版本级联标签与预设项。
  - **网盘独立配置区**：支持分别为夸克网盘和百度网盘录入/修改各自的文件容量、文件格式与内容说明。
  - **网盘链接独占整行排版**：夸克与百度网盘的 URL 地址输入框独占整行（100% 宽度），彻底杜绝操作按钮挤压输入框导致的截断问题；操作按钮（探测规格、一键转存换链）移至下方居中排列，排版舒适直观。
  - **彻底移除冗余共用字段**：废除表单中原有的全局“文件预估大小”输入项，各网盘规格由夸克与百度独立卡片管理并自动汇总，录入更轻巧直观。
  - 列表支持直接点击标题在新窗口预览前台，转存/浏览列细分显示各网盘具体转化数据。
  - 弹窗式修改编辑，支持一键切换上架/下架。
  - 无阻塞 Floating Toast 替代原生的弹窗拦截。
- **全网盘智能解析与自动洗链引擎 (⚡ 一键读取与 🔄 一键转存换链)**:
  - **全自动洗链与转存换链**：在录入或编辑资料时，管理员可直接粘贴他人分享的夸克链接，点击【🔄 一键转存为我的夸克链接】，后端自动将他人网盘文件秒级转存到站长个人网盘、并生成全新的专属永久公开分享链接（带站长官方拉新分成），同时自动识别提取文件大小、类型与名称回填至表单，彻底免除人工下载再重新上传。
  - **夸克网盘**：通过两阶段接口（Token 交换 + 详情与目录聚合）识别真实资源标题、文件夹层级及文件总容量（如 1.39 GB）与视频/PDF 格式标识。
  - **百度网盘**：支持提取码自动捕获、验证 Cookie 交换及接口/页面元数据抓取，精准自动回填百度端文件大小、文件格式及更新时间。
- **网盘账号与转存配置中心 (☁️ 多账号托管与独立沙盒)**:
  - **多网盘账号托管与毫秒级一键切换激活**：支持配置多个夸克网盘等平台的 Cookie 凭据与自定义账号备注名称（如“1号主力盘”、“2号拉新备用盘”）。管理员可随时点击任意账号卡片或【⭐ 设为默认】按钮毫秒级切换默认转存激活账号。默认激活账号采用专属**生机绿（Emerald Green）**高亮标识与边框，未激活账号采用轻量中性色，视觉主次逻辑分明。
  - **极速流畅的新建与表单重置**：列表头部提供【➕ 添加新网盘账号】快捷入口，表单提供【➕ 新增其他账号】与【清空表单】按钮，彻底消除编辑中无法便捷创建新账号的交互阻滞感。
  - **账号健康与空间容量看板 (精准超限预警)**：自动检测网盘连通性、实时刷新总容量与已用空间。针对历史存储超出当前配额的情况（如普通用户配额 10.1 GB，已占用 21.3 TB），精准标记“⚠️ 空间已超限”并高亮预警，避免转存失败。
  - **可视化目录管理器 (全路径精准识别与即时双重刷新)**：弹窗内嵌面包屑多级目录导航、子文件夹穿透。选定目标时自动计算并存储**多级全路径名称**（如 `/学习资料/高中数学/2026真题`），卡片与表单均清晰展示完整层级；新建多级子目录时支持**乐观秒级呈现 + 穿透时间戳防缓存刷新**，彻底消除新建二级目录不刷新的延迟。
  - **独立转存测试沙盒**：无需创建文章，可随心选择任意已托管账号或系统默认账号，输入他人夸克链接测试自动转存与专属换链。
- **顶级业务频道与扩展管理 (🏷️ 网站顶级频道管理)**:
  - **动态多垂类业务线管理**：支持开辟教辅资料（`edu`）、实用工具与素材（`tools`）、复古怀旧单机游戏合集（`games`）等顶级频道。
  - **一键上下线与隐藏控制**：支持一键切换频道为隐藏（`⚪ 已隐藏`）或上线（`🟢 已上线`），秒级响应。隐藏后前台导航与下属所有资源自动对外屏蔽。
  - **在库资源数量自动关联统计**：频道卡片自动聚合计算所属在库资料数。
  - **安全删除校验**：删除前强制验证关联资料数量，仅当关联资源清空后才允许删除，防止误删破坏业务数据。
- **网站多级导航与专区配置中心 (🧭 网站多级导航配置)**:
  - **全站多级专区自由管控**：独立工作台管理顶部一级专区与二级下拉菜单，告别代码级硬编码修改。
  - **树形可视化看板**：卡片式分层呈现一级专区与下属所有二级项，支持一键切换显示/隐藏、修改标题、更换 Emoji 图标、配置跳转路径与修改排序权重。
  - **内置快捷链接模板与热门角标**：创建与编辑菜单时提供常用学段与关键词快速模板（如 `/edu?stage=primary&q=小升初`），支持配置 `HOT`、`必刷`、`2026` 等视觉强化角标。
  - **资料本地化属性细分录入**：资料录入与编辑表单支持快捷填写“所属省市/地区”（如 `广西-柳州`）与“归属名校”（如 `柳州十二中`），直接对接精准搜索词引流。
  - **资源录入/修改无缝绑定频道**：资料表单支持可视化单选所属频道，资源列表支持按业务频道多维度切换过滤。
- **重点省市地区与名校字典库系统 (🏫 地区与名校库)**:
  - **结构化关联数据表 (`regions` 与 `schools`)**：外键关联保证一个地区下规范归属多所学校，杜绝重复敲字与命名分裂（如“柳铁一中”与“柳州铁一中”导致搜索无法聚合）。按站长要求严格剔除小学学校，全力聚焦中高考与择校高价值资料（初中 `junior`、高中 `senior`、完全中学 `all`）。
  - **资料表单智能级联点选器**：发布或编辑试卷时，选择地区（如“广西-柳州”）后自动弹出该地全部名校胶囊标签，点击 1 秒填入；若录入库中没有的新校，直接输入并点击【➕ 存入名校库】或直接提交表单，系统自动异步收录入库（智能推断初高中），永久保留。
  - **独立名校库工作台**：支持按地区卡片式查阅、修改、快捷补录新名校或清理废弃学校。提供初中、高中与完全中学学段分类。
  - **预置全量名校种子数据 (迁移自愈)**：内置 10 大重点考区与顶尖名校（柳州本地重点初中/高中、全国联考、海淀西城、黄冈、衡水、雅礼长郡等），写入 `docs/db_schema.sql`，数据库迁移重建时自动就绪。

### 2.3 后端核心服务 (Go Fiber v3 + GORM + PostgreSQL)
- **顶级业务频道核心引擎 (`internal/handler/channel_handler.go`)**:
  - `GET /api/v1/public/channels` (公开在线频道列表，只暴露 `is_active = true` 频道)
  - `GET /api/v1/admin/channels` (管理全量频道列表，包含 `resource_count` 资料聚合统计)
  - `POST /api/v1/admin/channels` (新建频道，含唯一 slug 校验)
  - `PUT /api/v1/admin/channels/:id` (修改频道信息与排序)
  - `PATCH /api/v1/admin/channels/:id/toggle` (一键切换上线/隐藏状态)
  - `DELETE /api/v1/admin/channels/:id` (级联安全校验删除)
  - **资源接口自动级联频道过滤**：`GET /api/v1/public/resources` 严格限制只返回处于有效上线频道（`channel_slug IN (SELECT slug FROM channels WHERE is_active = true)`）的在库资源。
- **夸克全自动转存与换链服务 (`internal/service/quark_transfer.go`)**:
  - 封装夸克官方 Web/PC 端私有协议（Token 鉴权、详情聚合、异步转存任务轮询、生成永久公开分享与提取码换取）。
  - 支持账号 Cookie 有效性自动检测与总/剩余容量实时计算。
- **网盘存活巡检服务 (`internal/service/netdisk_checker.go`)**:
  - 智能探测夸克分享 Token/状态及百度分享页面失效特征（如“页面不存在”、“分享已被取消”、“文件已被删除”等）。
  - 提供带延迟休眠的安全 Worker 检测队列，防止并发被网盘封禁。
- **网盘解析服务 (`internal/service/netdisk_parser.go`)**:
  - 夸克网盘与百度网盘公开/加密分享链接的自动化信息爬取、容量合并计算、格式识别与更新时间提取。
- **统一 RESTful API**:
  - `GET /api/v1/public/channels` (前台公开在线业务频道)
  - `GET /api/v1/public/resources` (前台公开资源列表，支持频道与学段过滤)
  - `GET /api/v1/public/resources/:slug` (资源详情直出)
  - `POST /api/v1/public/links/:id/report` (前台用户提交链接失效报错)
  - `GET /api/v1/admin/channels` (后台全量频道列表及资源数)
  - `POST /api/v1/admin/channels` (创建频道)
  - `PUT /api/v1/admin/channels/:id` (更新频道)
  - `PATCH /api/v1/admin/channels/:id/toggle` (一键切换上线/隐藏状态)
  - `DELETE /api/v1/admin/channels/:id` (安全删除频道)
  - `POST /api/v1/admin/links/:id/check` (单条链接手动立即探测)
  - `POST /api/v1/admin/links/batch-check` (后台一键巡检，带频率调控与冷却过滤)
  - `PUT /api/v1/admin/links/:id/status` (手动更新链接状态与补链)
  - `POST /api/v1/admin/parse-netdisk` (网盘智能解析接口，支持夸克与百度网盘及提取码)
  - `GET /api/v1/admin/netdisk/accounts` (获取托管的网盘账号列表)
  - `POST /api/v1/admin/netdisk/accounts` (添加/修改网盘账号并自动连通验证)
  - `DELETE /api/v1/admin/netdisk/accounts/:id` (删除网盘账号)
  - `POST /api/v1/admin/netdisk/accounts/:id/verify` (手动验证账号有效性与刷新容量)
  - `GET /api/v1/admin/netdisk/accounts/:id/folders` (获取网盘账号目录列表)
  - `POST /api/v1/admin/netdisk/accounts/:id/folders` (在线新建网盘文件夹)
  - `DELETE /api/v1/admin/netdisk/accounts/:id/folders/:fid` (在线删除指定网盘文件夹)
  - `POST /api/v1/admin/netdisk/transfer-share` (核心：自动转存外部链接并生成专属分享链)
  - `GET / POST / PUT / DELETE /api/v1/admin/resources` (后台管理全套 CRUD，支持按频道筛选)
