# 学霸网功能规格说明书 (FEATURES.md)

## 1. 核心定位与业务模式
学霸网（域名：`xuebaw.com`）是专为中小学与成人职考（教师资格证、考公、考研、职业技能）打造的网盘资源与精选学习资料聚合分享平台。核心在于轻体量、高转化、高裂变传播与网盘拉新返佣（夸克网盘为主、百度网盘为辅）。

### 2.2 管理后台 (Angular 21 + Reactive Forms)
- **管理员安全认证、改密与资料管理 (🔐 登录认证·JWT 鉴权·修改密码·全站拦截器)**:
  - **登录门禁与安全凭证拦截**：未登录用户访问后台时自动拦截至沉浸式暗黑毛玻璃卡片；支持标准用户名密码校验；严格遵循生产安全，页面不泄露任何默认密码提示；
  - **密码修改与个人资料更新**：顶部操作区集成【🔑 修改密码】入口，弹窗支持修改管理员显示昵称、原密码校验、两次新密码一致性比对与最小 6 位强度保护；
  - **全局 Angular HTTP 拦截器 (`authInterceptor`)**：全站自动为所有 `/api/v1/admin/*` 发送的请求挂载 `Authorization: Bearer <token>` 请求头；遭遇 401 凭证过期时自动清理缓存并退出至登录界面；
  - **账号信息持久化与同步**：登录成功后自动拉取管理员最新昵称与权限标识，顶部导航实时展示。
- **网盘转存数据分析与全站运营监控大屏 (📊 实时聚合·渠道分流·排行看板·搜索需求挖掘)**:
  - **全景数据大屏**：顶部带实时呼吸点灯与刷新控制，告别死数据，100% 由 PostgreSQL 真实数据库聚合驱动；
  - **四大核心 KPI 卡片**：直观监控全站网盘转存总数（与链接点击量）、全站浏览总量与综合转存转化率（`SaveRate`）、网盘链接存活健康率（正常 vs 异常）、在库资料与网盘账号状态；
  - **网盘渠道流向与占比**：按夸克网盘、百度网盘等平台分类统计链接量与转存点击量，提供多色渐变进度条呈现各渠道占比；
  - **顶级业务频道效益排行**：对比刚需教辅、实用工具素材、怀旧单机游戏等垂直频道的在库数、浏览量、转存量与该频道专属转化率；
  - **热门高转化资料排行榜 (Top 10)**：提取转存量最高的前 10 套精品资料，提供格式、浏览数、转存数与转化率明细，支持一键直达编辑补链；
  - **用户搜索需求热词捕获**：实时监控访客检索词，重点标识无结果的“🚨 库中暂缺 · 建议补录”稀缺资料，赋能站长精准备课与选品。

### 2.4 生产部署与多环境自适应架构 (Cloudflare Pages + Nginx 反代 + Systemd)
- **多端环境智能识别与零配置分流**:
  - **Angular 管理后台 (`apps/admin`)**：在 `ResourceService` 中内置宿主感知逻辑，本地开发 (`localhost`) 自动连接本地 `http://localhost:4001`；部署至 Cloudflare Pages 公网域名后，无需额外打包参数，自动无缝接入生产远端 `https://api.xuebaw.com:8443`；同时支持在浏览器控制台通过 `localStorage.setItem('API_BASE_URL', '...')` 覆盖指定 API 地址。
  - **Astro 用户前台 (`apps/web`)**：通过 `PUBLIC_API_URL` 环境变量、`wrangler.toml` 的 `[vars]` 配置及客户端运行期环境探针三级兜底，实现本地运行 `npm run dev` 连本地、发布上线自动连生产 API。
- **高可用、边缘加速与网络安全架构**:
  - **Cloudflare 边缘极速缓存与后台静默异步刷新 (方案一落地)**：全前台路由（`/`、`/:channel`、`/resource/:slug`）均挂载 `Cache-Control: public, max-age=60, s-maxage=300, stale-while-revalidate=86400`。
    - **极速响应**：新鲜期（5分钟）内全球访客直接由离其最近的 Cloudflare CDN 边缘节点 10ms~20ms 秒开直出；
    - **无感后台静默刷新**：过期时进来的首个访客无卡顿秒开现有缓存，CDN 同时在后台异步发起对国内服务器的拉取，静默更新节点缓存；
    - **天然源站隐身**：完全隐藏国内真实服务器 IP (`110.42.189.224`)，防御 DDoS 与脚本扫盘；
    - **单页面精准粒度**：各资源详情页各自分配独立缓存与刷新周期，修改某篇资料仅在该篇被访问时后台刷新，不影响其他页面。
  - **Nginx 多域名共享 8443 端口**：利用 SNI 技术让 `api.xuebaw.com` 与原有的 `api.puzzlepk.com` 共享单台服务器的 `8443` 端口，通过域名精准分流，解决端口冲突与证书隔离问题。
  - **Systemd 进程自愈**：后端 Go API 服务由 Linux systemd 守护进程管理（`Restart=always`），崩溃 5 秒自拉起，支持标准 journal 日志追溯与开机自启。
