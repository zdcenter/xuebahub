# 夸克网盘【学段/年级】精准文件夹共享与入库指南 (黄金实践)

## 一、 为什么【学段/年级】（如 `小学/一年级`）是最佳平衡点？

1. **工作量大幅压缩 90% 以上**：
   - 全库按学科划分有 122 个目录，而按【学段/年级】划分，**全国全学科总共仅 15 个文件夹**！
   - 您只需要分享 10 几个文件夹，就能覆盖全库 2032 本所有教材！
2. **符合用户真实使用习惯**：
   - 绝大多数家长/老师都是按“年级”找资料的（“我孩子今年上一年级”）；
   - 用户转存一个「小学一年级」文件夹，里面直接包含了语文、数学、道德与法治、科学等全部科目的最新教材，一次转存全搞定，体验极佳！
3. **系统智能回溯继承**：
   - 只要配置了 `"小学/一年级"` 的链接，该年级下所有 113 本书（各科目上册、下册）**自动全部绑定生效**！
   - 同时支持向下细化：如果您某一天对某门课（如 `小学/一年级/语文`）有特殊链接，只要填上也能单独精准覆盖。

## 三、 两种操作方式

### 方式 1：使用批量分享工具（最推荐，全自动生成）
运行交互工具：
```bash
python3 scripts/quark_batch_share.py
```
1. 依次输入序号进入：`keben_pdf` -> `小学`；
2. 此时屏幕列出 `[1] 一年级`、`[2] 二年级` ... `[6] 六年级`；
3. 输入 `s`（分享），然后输入 `1`（或者输入 `1-6`，或者输入 `all`）；
4. 工具自动调用夸克 API 为选中的年级生成永久免密公开链接；
5. 提示 `是否保存到配置文件？` 输入 `y` 自动排版写回！
6. 提示 `是否立即入库？` 输入 `y` 该年级的所有课本即刻上线！

### 方式 2：在网盘手动分享并粘贴到配置文件
打开配置文件：
[quark_category_links.json](file:///home/zd/netdisk/keben_pipeline/quark_category_links.json)

直接在最上方对应的年级填入链接即可：
```json
{
  "小学/一年级": "https://pan.quark.cn/s/xxxxxxxx",
  "小学/二年级": "https://pan.quark.cn/s/yyyyyyyy",
  ...
}
```
